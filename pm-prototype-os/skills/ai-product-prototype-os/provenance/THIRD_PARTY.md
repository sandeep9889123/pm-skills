# External design sources and attribution
Core documents are independently authored for PM Prototype OS, informed by public materials; no external binaries/assets are bundled. Optional sources:
- UI UX Pro Max, https://github.com/nextlevelbuilder/ui-ux-pro-max-skill, MIT; searchable UI knowledge and design-system approach.
- Impeccable, https://github.com/pbakaus/impeccable, Apache-2.0; UX critique, operating modes and deterministic design checks.
- Taste Skill, https://github.com/Leonxlnx/taste-skill, MIT; brief-based visual direction, redesign method and variance/motion/density dials.
- Existing PM Skills upstream: https://github.com/phuryn/pm-skills, MIT, author attribution preserved by parent repository.
No installation is automatic. If future contributions copy source code or assets, preserve the source license and required notices and review each license separately.
