# Conditional product artifacts
Always: problem/user/outcome brief, evidence states, constraints, success and acceptance criteria, scoped requirements, non-goals, risks, approval ledger, test plan, and a three-stage evidence-gated evolution view for new product initiatives. Multi-step UI: functional journey, screen inventory, errors/loading/empty/success states and roles. Persistent or relational data: logical data model/ERD and lifecycle. Service integration: API contract, security boundary, failure paths. AI system: model strategy, retrieval/tools if relevant, prompt-injection boundary, latency/cost, evaluator dataset, human review. Enterprise: tenant separation, RBAC, audit events. Mobile: connectivity, platform permissions and device adaptation. Do not fabricate absent material; declare omitted artifacts with reasons; lightweight output is fine when complete.
