# Question gate
At the beginning of EVERY distinct user task ask 5–10 concise, relevant, nonduplicate questions and wait. Use at least five even for a small task. Do not re-ask settled inputs; ask confirmations, acceptance tests or unresolved trade-offs instead. Phase-approval replies for an already scoped task do not restart this gate. If the user skips questions, explain the agreed contract and request a governance change; no silent bypass. Capture user answers and question IDs in the phase record. State whether EXPLORE/BUILD/IMPROVE and which product archetypes are activated. Involve the user in defining decisions; do not overwhelm with irrelevant questions.
