# Zero incremental cost policy
No new charges. Existing subscriptions and genuinely free local/free-tier capabilities may be used only within available user permissions. Before any installation, model download, paid API call, hosted resource, deploy, external integration or company-data access, verify the current phase approval and the possibility of charges. Unknown pricing or leakage risk => stop and request clarification. Do not create credit-card-backed services silently. Offline mock/demo options preferred by default. If limits exceeded, pause; never infer consent to spend.
