# Prototype UX quality

Every new task begins with 5–10 relevant questions; await scoped phase approval. Choose Operate (apps, workflows), Persuade (marketing), Read (documentation), or Experience (showcase) from surface intent. Prioritize accessible task completion, content hierarchy, consistent typography/tokens, forms, focus and keyboard operation, responsive layouts, useful states, data tables and charts where appropriate. Use context-sensitive design variance, motion and density. Critique existing UI before redesign; verify no dead controls and document known defects. UI UX Pro Max, Impeccable, Taste Skill are optional inspirations and optional executable adapters, not required dependencies; do not install them automatically.
