# AI solution architecture
Before new task work apply the 5–10-question and approval gates in the canonical ai-product-prototype-os skill, which remains authoritative. For an approved technical phase: map user intent and measurable AI need; compare rule-based, mock, local model and API options. Model the data and security boundaries, tools/action permissions, failure modes, latency and zero-incremental-cost assumptions. Include retrieval/citation/evaluation for RAG, human authorization/traces/rollback for agents. Deliver architecture diagram, alternatives, acceptance tests and phase handoff; code only in an approved implementation phase. If main skill absent, still ask 5–10 questions and stop before authorizing any phase.
