# /start-prototype
Load the **ai-product-prototype-os** skill and the relevant archetype references. Treat this as a new task: ask 5–10 context-specific questions about problem, users, alternatives, goals, evidence, outcomes, constraints, budget, data and demo fidelity; stop for answers. Only after answers classify Explore/Build/Improve, create a scoped discovery proposal, identify optional vs mandatory artifacts, challenge weak assumptions and ask for explicit approval. Never silently begin implementation.
