# PM Toolkit

Utility workflows for PM writing, resume review, proofreading, NDA drafting, privacy policy drafting, and other practical PM support tasks.

This plugin is part of Sandeep Kumar M's enhanced `pm-skills` fork. It is a supporting toolkit, not the core strategy layer. Use it when the PM job requires clean artifacts, polished communication, or quick structured drafts.

## When to use

Use this plugin when you need to:

- review or tailor a resume
- proofread PM writing
- draft simple NDA language
- draft privacy-policy starter content
- clean up stakeholder-facing communication
- create lightweight utility artifacts

## Skills included

- `draft-nda`
- `grammar-check`
- `privacy-policy`
- `review-resume`

## Commands included

- `/draft-nda`
- `/privacy-policy`
- `/proofread`
- `/review-resume`
- `/tailor-resume`

## Operating rules

1. Do not imply legal advice for NDA or privacy-policy drafts.
2. Use clear caveats where expert legal review is required.
3. Resume feedback should be specific, role-aligned, and evidence-based.
4. Proofreading should preserve meaning and sharpen clarity.
5. Do not add fake achievements, metrics, employers, clients, or credentials.
6. PM utility outputs should be concise and ready to edit.

## Example use

```text
Use pm-toolkit to review this PM resume for enterprise AI PM roles. Identify weak signals, missing proof, positioning gaps, and rewrite the top bullets with stronger ownership framing.
```

## Output standard

A strong output from this plugin should include:

- diagnosis
- rewrite or draft
- risk notes
- assumptions
- improvement suggestions
- final polished version where applicable
