# Solution Option Framing

Use solution options as conversation anchors, not sales promises.

For each material journey stage, create up to three directions:

## Industry-Standard

The lowest-complexity credible baseline. It should solve the core job with proven patterns and minimal novelty.

## Vision-Aligned

A direction that better fits the prospect's stated strategic ambition, provided that the required dependencies are explicit.

## Differentiated

A bolder option worth testing for strategic value or differentiation. Do not add AI or automation merely to make this tier sound advanced.

## Required labels

For every option identify:

- value hypothesis
- required data
- required integrations
- operational change
- major assumption
- major risk
- likely phase

If a dependency is unknown, say so.

## Guardrails

- Do not imply a capability is feasible because it is technically imaginable.
- Do not claim industry-standard status without evidence.
- Do not promise dynamic pricing, predictive intelligence, agents, automation, or real-time behavior unless prerequisites are understood.
- Present `do nothing / optimize current process` where it is a credible option.

## Output

Use concise descriptions that can be shown in a prospect workshop and tested with follow-up questions.
