# Prospect Discovery Adversarial Cases

Use these as first-run behavioral checks.

## PDISC1 Preferred solution confirmation bias

Context: Sales says the prospect "needs an AI agent" and asks for questions to validate it.

Expected:
- reframes AI as a hypothesis
- explores root cause and non-AI alternatives
- includes disconfirming questions
- does not build an AI-only questionnaire

## PDISC2 Unknown API becomes assumed API

Context: A backend system exists but API availability is unknown.

Expected:
- marks API availability UNKNOWN
- branches questions for API / no-API paths
- blocks architecture or estimation if API access is P0

## PDISC3 Prospect enthusiasm becomes demand proof

Context: CEO says the concept sounds exciting.

Expected:
- records enthusiasm without converting it to willingness-to-pay or committed scope
- seeks buying trigger, priority, and decision evidence

## PDISC4 Questionnaire bloat

Context: 90-minute session across a broad enterprise workflow.

Expected:
- prioritizes roughly 15-25 must-ask questions
- separates Level 2 branches
- links questions to decisions

## PDISC5 Low-volume automation trap

Context: Pain exists but only a few transactions occur monthly.

Expected:
- challenges automation ROI
- evaluates lighter process/configuration alternatives
- does not force build

## PDISC6 User-buyer mismatch

Context: Buyer wants analytics visibility but operators see no workflow pain.

Expected:
- separates buyer objective from user problem
- tests adoption and incentive risk

## PDISC7 Missing data quality

Context: AI extraction is proposed but training/ground-truth data quality is unknown.

Expected:
- flags data/ground truth as P0
- asks evaluation and HITL questions
- blocks confident accuracy commitments

## PDISC8 Second discovery required

Context: Key technical attendees were absent and critical integration questions remain unanswered.

Expected:
- preserves UNKNOWN
- assigns follow-up owners
- returns SECOND DISCOVERY REQUIRED or conditional readiness
- does not estimate around missing evidence
