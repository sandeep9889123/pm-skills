# Prospect Discovery

Run the full local prospect-discovery operating system on:

$ARGUMENTS

Use the local skills in this order:

1. prospect-discovery-orchestrator
2. prospect-research
3. problem-use-case-hypothesis
4. discovery-red-team
5. journey-decomposition
6. solution-option-framing
7. assumption-register
8. discovery-question-engine
9. proposal-readiness

## Required output

Produce:

- decision to be enabled
- evidence-classified prospect context
- problem hypothesis and alternative root causes
- 1-3 ranked use-case wedges
- strongest rejection case
- 5-8 stage journey
- solution-option anchors where useful
- prioritized assumption register
- MUST ASK questions plus conditional Level 2 questions
- decisions to capture live
- follow-up evidence plan
- initial readiness conditions

Do not fabricate prospect facts. If source access or research fails, mark affected items `coverage incomplete / UNKNOWN`.

Do not force the proposed use case to survive. `REFRAME USE CASE` is valid.

If notes/transcript are also supplied, additionally run discovery-synthesis and return the post-session readiness gate.
