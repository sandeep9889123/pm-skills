# Discovery Prepare

Prepare the pre-call discovery pack for:

$ARGUMENTS

## Sequence

1. Define the exact next decision this meeting must enable.
2. Research only what materially improves the meeting.
3. Separate FACT / INFERENCE / ASSUMPTION / UNKNOWN / STALE.
4. Build the problem hypothesis and alternative root causes.
5. Rank 1-3 candidate use cases without privileging the user's preferred wedge.
6. Red-team the leading wedge before writing questions.
7. Decompose the flow into 5-8 stages.
8. Create solution directions as hypotheses, not commitments.
9. Create a prioritized assumption register.
10. Generate 15-25 high-yield MUST ASK questions for a 60-90 minute session, adjusted to the actual duration.
11. Add conditional Level 2 branches.
12. End with decisions to capture and P0 evidence gaps.

## Question gate

Every MUST ASK question must state which material decision it can change.

Remove questions that only make the document look comprehensive.
